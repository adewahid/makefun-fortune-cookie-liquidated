One fortune-cookie line for a crypto trader who just got liquidated,
written by `main.ts` to `/output/entry.txt`:

> You will rise again, wealthier in wisdom — the market merely borrowed your money indefinitely.

## Run

```sh
node main.ts
cat /output/entry.txt
```
